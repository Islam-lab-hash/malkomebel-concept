# MalkoMebel concept

Многостраничный статический концепт сайта Малко-Мебель в редакционном чёрно-белом стиле с тёплой бумажной подложкой, округлёнными фотографиями и спокойной анимацией.

Основные страницы: главная, каталог, материалы и фурнитура, услуги, цены, конструктор, заявка онлайн, отзывы, контакты, политика и карта сайта.

Раздел `archive.html` содержит ссылки на 1 014 отдельных переработанных страниц исходного публичного сайта. В каждой странице сохранены исходные заголовки, описания, текстовые фрагменты и ссылка на оригинал. Полный локальный архив исходного HTML и 5 910 ассетов находится в рабочей папке `MalkoMebel_Concept/source-archive`.

Публичный предпросмотр: https://islam-lab-hash.github.io/malkomebel-concept/
