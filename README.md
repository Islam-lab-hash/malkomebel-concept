# MalkoMebel Concept

Многостраничный концепт обновлённого сайта Малко-Мебель.

## Просмотр

Локальный preview: `concept-site/preview/index.html`

Страницы концепта:

- Главная
- Каталог
- Материалы и фурнитура
- Услуги
- Цены
- Конструктор
- Заявка онлайн
- Контакты

## Архив источника

Папка `source-archive` содержит публично доступные HTML-страницы и assets исходного сайта, собранные с sitemap. Приватные и запрещённые robots.txt разделы не включались.
